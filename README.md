# 水下考古潜水记录

直接打开 `index.html` 使用（无需构建、无需服务器）。点击沉船平面图添加标本标记，支持筛选、编辑、潜次签核、修订历史与导出 JSON。

## 工作流程

1. **登记与编辑**：标本挂在潜次下，潜次未签核前可照常编辑、删除，直接覆盖原记录。
2. **潜次签核**：在「潜次签核」面板对潜次执行签核定稿（空潜次不能签核）。签核后该潜次所有标本定稿。
3. **签核后更正**：已签核标本的更正必须填写修订原因，保存时生成新修订版本；旧版本保留并在时间线中标记「已被替代」。编号与潜次不可再改。
4. **移除**：未签核标本可直接删除；已签核标本移除必须填写原因，记录保留在时间线中。
5. **地图与导出**：地图和导出的 JSON 只取每个标本的最新版本（已移除的不出现）；「潜次时间线」视图可展开每个标本查看全部历史版本与修订原因。

## 代码分层

| 文件 | 职责 |
| --- | --- |
| `js/data-store.js` | 数据存取层：状态容器、localStorage 读写、id/时间戳生成 |
| `js/domain.js` | 规则层：签核、版本修订、移除原因、最新版本/历史查询，不触碰 DOM |
| `js/ui.js` | 展示层：DOM 渲染与交互，把操作转交给规则层 |
| `index.html` | 页面结构与样式，按顺序加载以上三个脚本 |

数据存放在 localStorage（键 `uwaStateV1`），首次打开自动写入示例数据。
