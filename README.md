# 水下考古潜水记录

直接打开 `index.html` 使用（`file://` 即可，无需构建）。数据保存在浏览器 localStorage。

## 功能

- 点击沉船平面图添加标本标记，支持类型筛选、编辑、删除与 JSON 导出。
- **潜次签核**：输入审核员后签核。签核前标本可正常编辑，保存直接覆盖当前记录。
- **签核后修订留痕**：已签核潜次下的更正不会覆盖旧记录，而是新建一个修订版本；旧版本保留并标记「已被替代」，修订时必须填写原因。签核后补录新标本同理。
- **最新版本视图**：地图、标记列表与导出只取每个标本的最新版本；被修订过的标本有「已修订」角标，导出含 `version`、`revised`、`revisionReason` 字段。
- **历史时间线**：按潜次展示登记、签核后补录、历次修订（含原因）、潜次签核与移除事件；点击任意旧版本可只读查看，横幅标明版本序号与替代状态。
- **潜次移除**：含已签核标本时必须填写移除原因，原因与移除时间进入历史时间线；被移除潜次下的标本不再出现在地图与导出中，但历史仍可查。

## 代码组织（数据存取 / 规则判断 / 页面展示分离）

| 文件 | 职责 |
| --- | --- |
| `js/store.js` | 数据存取层：localStorage 读写（键 `zfl30State.v2`）、种子数据、旧版扁平数据（`zfl30Marks`）自动迁移 |
| `js/domain.js` | 规则判断层：签核、修订、补录、删除、移除的纯业务规则；最新版本投影与时间线汇总；不接触 DOM |
| `js/ui.js` | 页面展示层：地图标记、表单、列表与时间线渲染及交互；只通过 `Domain` / `Store` 访问数据 |
| `index.html` | 页面结构与样式，按上述顺序引入三个脚本 |

核心数据结构：`dives[]`（潜次及签核/移除信息）与 `specimens[].versions[]`（每版含 `status: current | superseded`、`createdAt`、`revisionReason`）。
